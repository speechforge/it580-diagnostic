# IT 580: Student Knowledge Gap & Targeted Revision Portal

**DA-IICT IT 580: Data Structures and Algorithms (Assignments 5 to 12)**

Interactive, student-specific diagnostic & targeted revision portal. Students can review customized chapter-by-chapter learning points, core invariants, common exam pitfalls, and detailed question breakdowns without exposing numerical marks or class rankings.

## 🚀 Live Static Deployment
- **URL**: [https://speechforge.github.io/it580-diagnostic/](https://speechforge.github.io/it580-diagnostic/)

## 🔑 Access Model
- **Contact-First Verification**: Zero public identity leakage. Students verify access by entering their registered mobile contact number (or Student ID).
- **Pedagogical Revision Flow**: Core invariants, recurrence relations, and exam pitfalls are presented first. Students click each chapter to inspect question-level explanations.
